# bmms-core

Billing engine: bills, transactions, holds and cancels, reconciliation, bookkeeping, deposits, virtual accounts, P2P transfers.

Stack: Java 11, Spring Boot 2.4.7, PostgreSQL, Oracle, Liquibase, OpenFeign, WebFlux, Keycloak, Apache POI, SOAP, MapStruct, Hazelcast, Maven.

Run:

```bash
./mvnw spring-boot:run
```

Settings come from environment variables.
